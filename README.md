# Duplicate File Finder v1.0
A fast, lightweight, and beginner-friendly **Duplicate File Finder** for Windows built using **C++ and Qt**.

This tool scans any folder on your computer and detects duplicate files using secure hashing. It helps you clean up storage, remove unnecessary files, and organize your system more efficiently.

---

##   Features
- Select any folder to scan
- Fast duplicate detection (hash-based)
- Clean and simple UI
- Highlight duplicate groups
- Delete duplicate files from inside the app
- Lightweight: no installation required
- 100% offline — no data leaves your PC

##  How It Works
1. Choose a folder  
2. Start scanning  
3. Wait for the analysis to complete  
4. View duplicate groups  
5. Delete duplicates safely using in-app controls
